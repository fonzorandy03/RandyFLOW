# Prompt per creare uno Study Package pagina per pagina

Il prompt completo è disponibile nella pagina **Studio** dell'applicazione tramite il pulsante **Copia prompt**. La sorgente mantenuta dall'app si trova in `lib/study-package-prompt.ts`.

Il prompt impone:

- conteggio reale del PDF prima della generazione;
- un topic distinto per ogni singola pagina;
- spiegazione semplice, normale e approfondita per ogni pagina;
- riassunto, concetti ed esempi per ogni pagina;
- almeno un quiz, una flashcard e una domanda d'esame per ogni pagina;
- controllo finale senza pagine mancanti, duplicate o rinumerate;
- contenuti fedeli alla pagina indicata, senza informazioni inventate.
